# BP 打磨舱 · 双创赛事商业计划书诊断平台 — 诊断报告清单

**全局基线**：上传后 ≤5 分钟出报告（实测 PDF/PPTX 本地解析 0.1–3 秒）；风险项 ≤10 条并按严重度排序；每条必带一条「补救动作」；报告区一律清单式，不写段落式评语；路演按 5 / 8 / 15 分钟三档裁剪（240 字/分钟）。
**硬约束**：① 禁止吹捧式反馈——不出现「前景广阔」「团队优秀」「很有潜力」，只输出风险、证据、动作；② 禁止虚构市场数据与引用——所有规模、增长率、渗透率必须用户自填参数后由公式算出，工具不设默认值、不引用行业报告；③ 不得承诺获奖概率——不做获奖率、晋级率、评分预测，只做逻辑校验与表达打磨。
**迭代说明**：第 04 模块由「AI 扮演毒舌评委追问 3 轮」调整为「AI 先追问 2 轮，第 3 轮改为给出一段示范应答并要求团队改写自己的版本」；其余四模块、硬约束与视觉基调保持不变。
**视觉基调**：深灰 `#232428` 作主色（深色评委卡 + 灰阶评分块）+ 警示橙 `#E2622A` 作唯一强调色（只用于风险、未达标、待办动作），底 `#F2F1ED`；报告区用表格与清单，不用段落。

### 01 BP 十二页结构模板

- **环节**：12 页 × 每页 3 道必答题，按 P0/P1/P2 排优先级，空页不进路演稿、不进诊断。
- **AI 提示词原文**：
```text
你是双创赛事评委。按12页骨架（封面定位/痛点验证/方案形态/技术壁垒/市场测算/商业模式/竞品差异/落地进展/团队分工/财务融资/社会价值/风险里程碑）逐页检查。每页只问3题，必须问「数字从哪来、谁验证的、不成立时怎么办」。用户答完后：①标出该页缺的字段；②只给一条补救动作；③给再评估标准。禁止评价写得好不好，禁止给范文代写，禁止替用户补任何数据。
```
- **界面**：左侧 12 页列表（显示 n/3 完成度），右侧该页三问编辑区 + 上/下页 + 导出 Markdown。
- **输出字段**：页码 / 标题 / 优先级 / 三问 / 我的答案 / 完成度。
- **裁剪联动**：P0（封面、痛点、方案、技术、商业模式、进展）→ 5 分钟档必留；P1 → 8 分钟档；P2 → 仅 15 分钟档。
- **验收口径**：36 格全部有内容，路演稿生成率 100%；未填页在稿中直接缺席并被列出。

### 02 评委视角 30 问挑战库

- **环节**：5 维度 × 6 问，逐题作答后即时判定「过 / 存疑 / 未答到点」，判定只数答到几个要点。
- **AI 提示词原文**：
```text
你是评委，出5维度各6问（技术可行性/市场规模/商业模式/团队结构/社会价值）。每题预设3个必答要点，用户作答后按命中要点数判定：≥2过、1存疑、0未答到点。反馈固定三段：①命中（引用其原词）②缺口（缺哪个要点）③追问（一句更狠的追问）+ 一条今天能做的动作。禁止夸，禁止给标准答案，禁止补充用户没说的事实。
```
- **界面**：维度标签（带 0–12 得分）+ 题卡（要点提示 / ≤120 字作答 / 判定徽章 / 反馈块）。
- **输出字段**：维度 / 题号 / 问题 / 作答 / 命中要点 / 缺口要点 / 判定 / 补救动作。
- **验收口径**：30 题判定可复现（同答案同判定）；判定结论必带一条动作；无一处出现「很好 / 不错 / 有想法」。

### 03 路演稿生成与三档裁剪

- **环节**：按 240 字/分钟折算三档字数（1200 / 1920 / 3600 字），由 12 页答案自动拼稿并按时长裁剪。
- **AI 提示词原文**：
```text
把用户12页答案改写成路演口语稿，只搬运他写的事实，不新增任何数据与案例。按优先级裁三档：5分钟只留P0、8分钟留P0+P1、15分钟全留。每页给出建议秒数与字数，超出上限时按字数从多到少列出删除顺序。稿子超时或某页为空时直接标灰，不替他补话。
```
- **界面**：三档卡片（含字数上限）+ 倒计时器 + 逐页稿（左页码/秒数，右正文）+ 超时提示 + 不念页删除顺序。
- **输出字段**：档位 / 目标字数 / 实际字数 / 每页秒数 / 正文 / 被裁页与删除顺序。
- **验收口径**：三档切换 ≤ 0.2s；字数误差 ≤ 5%；5 分钟档只含 P0 页；超时项必须显式标出。

### 04 毒舌评委 · 三轮答辩模拟（迭代版）

- **环节**：前 2 轮只追问不给答案；第 3 轮先给一段示范应答，要求团队按同结构改写自己的版本，再逐项对照。
- **AI 提示词原文**：
```text
你是毒舌评委。第1轮：从30问中挑他最弱的一题，只问，不点评。第2轮：抓住他第1轮答案里的一个数字或形容词往下追（谁给的/什么口径/换个数还成立吗）。第3轮：不再提问，给一段四段式示范应答——结论（一句话不铺垫）/证据（来源+时间+口径+样本量）/边界（什么条件下不成立）/下一步（30天动作+验收指标），要求他按此骨架改写自己的版本；收到改写后只做四项对照（结论是否前置/证据是否带出处/是否承认边界/是否有收口动作），逐项标有或无并给一句缺什么，不打分、不评价文笔、不代写内容。
```
- **界面**：三轮进度条 → 深色评委卡（问题 + 一句追问理由）→ 作答区；第 3 轮为「示范卡 + 改写框 + 四项对照卡」。
- **输出字段**：轮次 / 评委问 / 团队答 / 对照四项（有·无）/ 缺什么 / 导出记录。
- **验收口径**：第 3 轮必须出现示范应答，且示范中的数字一律为 XX 占位（不提供可抄的假数据）；对照恒为 4 项；三轮记录可导出。

### 05 上传 BP · 输出诊断报告

- **环节**：本机解析 PDF / PPTX / TXT / MD（不上传服务器），按 5 维度扫规则，出清单式报告。
- **AI 提示词原文**：
```text
你是评委，只做逻辑校验。读取BP全文，按5维度（技术可行性/市场规模/商业模式/团队结构/社会价值）各打1–5分；输出风险项，总数≤10，按P0阻断/P1重要/P2提示排序。每条必须：引用BP原文≤26字作证据、给一条今天能做的补救动作、给一条可验收的再评估标准。严禁：编造数据、引用行业报告替用户补数字、给获奖概率、写段落式评语。缺失型风险写「全文未出现……」并指出缺哪几项。
```
- **界面**：拖拽上传 + 粘贴兜底；市场规模自算台（4 参数，缺一不出结果）；五维度六字段表格；风险清单（编号 + 严重度 + 证据 + 动作 + 再评估）。
- **输出字段**：评审维度 / 评分 1–5 / 风险项 / 证据（BP 原文）/ 补救动作 / 再评估标准。
- **量化**：出报告 ≤5 分钟（实测秒级）；风险 ≤10 条，按维度保底配额后按严重度排序；每条均有动作与再评估。
- **验收口径**：改完任一条后重新上传，该条须从清单消失；同一份 BP 同一参数两次诊断结果一致。

## 附一：诊断报告输出样例（5 维度 × 6 字段，每维度 ≤250 字）

> 说明：以下为对一份**刻意写得空泛**的示例 BP 的输出，用于展示字段口径。示例 BP 中的金额为占位文本，不含任何真实市场数据；所有测算数字均须用户自填参数后生成。

**1. 技术可行性｜评分 2/5**
- **风险项**：技术优势用形容词代替证据；未给出成熟度等级与对照基线。
- **证据**：「我们的产品采用先进的人工智能算法，技术国际领先，能够彻底解决……」
- **补救动作**：删掉「国际领先」，改写成一句对照句——在（对照组）下，我们的（指标）从 A 变成 B；附检测机构名与报告编号。
- **再评估标准**：技术页出现至少一组「指标 + 基线 + 出处」，且不含排名式形容词。

**2. 市场规模测算｜评分 1/5**
- **风险项**：有数字无性质说明；引「据统计」无报告名；缺自下而上测算路径。
- **证据**：「市场规模有望达到千亿级别……据统计，未来几年将保持高速增长。」
- **补救动作**：删掉千亿与「据统计」，改填四参数：可触达用户数 × 渗透率 × 客单价 × 年频次，各注明来源；算不出就先写「暂未测算，X 月前完成 30 份用户访谈」。
- **再评估标准**：BP 中出现可复算的测算式，四参数均有出处，且与自算 SOM 偏差 ≤3 倍。

**3. 商业模式｜评分 2/5**
- **风险项**：付费方与用户混谈；无客单价、成本、毛利；进展无真实数据。
- **证据**：「采用 B 端收费、C 端免费的模式，未来还将拓展广告、数据服务等更多盈利渠道。」
- **补救动作**：补三行——谁付钱（角色）、一单收多少、毛利多少；再补三个带日期的进展数（付费用户 / 合同金额 / 近 6 个月关键指标），为 0 就写 0。
- **再评估标准**：付费方、客单价、毛利率三项可直接找到数字；进展页有三个带日期的事实。

**4. 团队结构｜评分 1/5**
- **风险项**：团队描述是评价不是分工；无单一责任人；无投入时间与股权约定。
- **证据**：「团队由多名优秀在校大学生组成，专业背景多元，结构合理，执行力强。」
- **补救动作**：改成表格四列：姓名 / 专业年级 / 负责什么 / 每周投入小时；补一句「分歧由谁拍板」，并写明股权比例。
- **再评估标准**：团队页为表格，四列齐全；每人只有一个主责；出现决策人姓名。

**5. 社会价值｜评分 2/5**
- **风险项**：只有口号没有数字；受益人数无统计口径；未说明公益与营收的关系。
- **证据**：「本项目将带动就业，助力乡村振兴，具有良好的社会效益。」
- **补救动作**：选一项做实——受益人数（口径 + 来源）、带动就业人数、或单户节本金额；再写明公益部分由哪块收入补贴。
- **再评估标准**：社会价值页每项均有数字 + 口径 + 来源；公益与商业的补贴关系写明。

## 附：字数与口径自检

- **字段口径**：报告恒为 6 字段（评审维度 / 评分 / 风险项 / 证据 / 补救动作 / 再评估标准），五维度逐项输出，每维度正文 ≤250 字。
- **证据口径**：每条证据必须是从 BP 原文截取的 ≤26 字片段，前后加省略号，不改写、不概括。
- **动作口径**：每条补救动作必须以动词开头（删掉 / 改写成 / 补上 / 填成），且可在当天或 30 天内完成。
- **不出现的内容**：任何「前景广阔 / 团队优秀 / 很有潜力」式评价；任何未经用户填参的市场数字；任何行业报告名称与引用；任何获奖率、晋级率、评分预测；任何段落式长评。
